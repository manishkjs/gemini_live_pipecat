## Speech in, speech out in real time

The **Gemini Live API** is a stateful, bidirectional streaming API. Open a single WebSocket, stream 16 kHz microphone audio in, and receive 24 kHz generated speech back as it is produced, with built-in turn-taking and barge-in interruption.

This guide covers the wire protocol, client audio engineering, unit economics, and production patterns required to run voice agents reliably at scale.

:::tip[Native duplex or STT-LLM-TTS cascade?]
Gemini Live supports **native audio** (one model performs speech-to-speech) alongside traditional **cascade** pipelines (Speech-to-Text -> LLM -> Text-to-Speech). See [Choosing a framework -> Native S2S vs. cascaded STT -> LLM -> TTS](/gemini_live_pipecat/frameworks/#2-native-s2s-vs-cascaded-stt--llm--tts-inside-frameworks) for the architectural and cost tradeoffs.
:::
