## Speech in, speech out — in real time

The **Gemini Live API** is a stateful, bidirectional streaming API. You open a
single WebSocket, stream microphone audio in, and receive generated audio (and
transcripts, tool calls, and events) back as it is produced — with natural
turn-taking and barge-in interruption.

This site is the practical field guide: the wire protocol, the failure modes,
and the operational patterns that separate a demo from a production voice agent.

:::tip[Two ways to do speech]
Gemini Live offers **native audio** (one model does speech-to-speech) and a
**cascade** (Speech-to-Text -> LLM -> Text-to-Speech). This guide covers both.
See [Architecture](/gemini_live_pipecat/architecture/) for how to choose.
:::
