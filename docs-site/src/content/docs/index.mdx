## Speech in, speech out in real time

The **Gemini Live API** is a stateful, bidirectional streaming API. You open a single WebSocket, stream microphone audio in, and receive generated speech back as it is produced, with natural turn-taking and barge-in interruption.

This documentation is a practical engineering guide covering the wire protocol, failure modes, and production patterns needed to run voice agents reliably.

:::tip[Two ways to run speech]
Gemini Live supports **native audio** (one model performs speech-to-speech) and a
**cascade** pipeline (Speech-to-Text -> LLM -> Text-to-Speech). This guide covers both.
See [Architecture](/gemini_live_pipecat/architecture/) for how to choose.
:::
