## 2. What the skill enforces (Executive cheat sheet)

| Domain | Rule Enforced by `SKILL.md` | Why It Matters | Deep-Dive Guide |
| :--- | :--- | :--- | :--- |
| **Modality Lock** | Always set `responseModalities: ["AUDIO"]` (never `["AUDIO", "TEXT"]`) and enable transcripts via `inputAudioTranscription` / `outputAudioTranscription`. | Specifying both `AUDIO` and `TEXT` in `responseModalities` triggers an immediate WebSocket `1007` protocol error. | [Configuration & Prompting](/gemini_live_pipecat/gemini-live-configuration/) |
| **PCM Audio Pipeline** | Stream **16kHz** 16-bit mono PCM in **20–40ms** chunks on input; play back **24kHz** 16-bit mono PCM on output. | Prevents chipmunk/slow-motion pitch distortion and high VAD latency from oversized audio buffers. | [Audio, VAD & Barge-In](/gemini_live_pipecat/audio-engineering/) |
| **10m & 15m Session Limits** | Always pair `sessionResumption` (for 10m WebSocket rotation) with `contextWindowCompression` (`SlidingWindow` for the 15m audio cap). | Allows calls to run for 60+ minutes without disconnects or context-window exhaustion. | [Architecture & Lifecycle](/gemini_live_pipecat/architecture/) |
| **Prompt Hygiene** | Strip all square brackets, markdown formatting, and monolithic multi-phase instructions from `systemInstruction`. | Prevents the native audio model from reading stage directions aloud or burning thousands of tokens per turn. | [Configuration & Prompting](/gemini_live_pipecat/gemini-live-configuration/#prompting-for-native-audio-models) |
| **Async Tool Shielding** | Wrap backend tool executions in `asyncio.shield()` and control spoken timing with `FunctionResponseScheduling` (`WHEN_IDLE`, `SILENT`, `INTERRUPT`). | Ensures user barge-in only flushes audio playback and never cancels in-flight database writes or drops `toolResponse` frames. | [Tool Calling & Async](/gemini_live_pipecat/tools/) |
| **3-Pillar Cost Control** | Cap carried audio with `SlidingWindow(5000/3500)`, inject JIT Phase Cards (~500 tokens avg) between turns, and pin early facts in a `<60-token` JSON `FactStore`. | Cuts 10-minute call costs by **82%** (from `$0.178/min` down to **`$0.031/min`**) with zero loss of early-call facts. | [Optimization Patterns](/gemini_live_pipecat/optimization/) |
| **Cloud Run Flags** | Deploy in `us-central1` with `--no-cpu-throttling --timeout=3600 --session-affinity --concurrency=20`. | Prevents CPU freezes between audio frames and 5-minute load-balancer disconnects. | [Cloud Run Deployment](/gemini_live_pipecat/deployment/) |

## 3. Canonical production configuration (`google-genai`)

```python
from google import genai
from google.genai import types

client = genai.Client(
    vertexai=True,
    project="your-gcp-project-id",
    location="us-central1",
)

# Replace None with the latest SessionResumptionUpdate.new_handle on reconnect
saved_handle: str | None = None

config = types.LiveConnectConfig(
    response_modalities=[types.Modality.AUDIO],
    speech_config=types.SpeechConfig(
        voice_config=types.VoiceConfig(
            prebuilt_voice_config=types.PrebuiltVoiceConfig(voice_name="Aoede")
        )
    ),
    system_instruction=types.Content(
        parts=[
            types.Part.from_text(
                text=(
                    "You are a concise, helpful customer support specialist. "
                    "Keep spoken responses to 1 to 2 short sentences per turn. "
                    "Never use markdown formatting, bullet points, or bracketed stage directions."
                )
            )
        ]
    ),
    input_audio_transcription=types.AudioTranscriptionConfig(),
    output_audio_transcription=types.AudioTranscriptionConfig(),
    realtime_input_config=types.RealtimeInputConfig(
        automatic_activity_detection=types.AutomaticActivityDetection(
            disabled=False,
            start_of_speech_sensitivity=types.StartSensitivity.START_SENSITIVITY_HIGH,
            end_of_speech_sensitivity=types.EndSensitivity.END_SENSITIVITY_LOW,
            prefix_padding_ms=200,
            silence_duration_ms=500,
        )
    ),
    session_resumption=types.SessionResumptionConfig(handle=saved_handle),
    context_window_compression=types.ContextWindowCompressionConfig(
        trigger_tokens=5000,
        sliding_window=types.SlidingWindow(target_tokens=3500),
    ),
)
```
