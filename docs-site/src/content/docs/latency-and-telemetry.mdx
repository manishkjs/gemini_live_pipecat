In a real-time voice conversation, standard HTTP metrics like "total request duration" are meaningless because the WebSocket remains open for 10 to 60 minutes. Instead, voice engineering teams track **per-turn voice-to-voice latency** and **per-turn token consumption**.

---

## 1. Anatomy of a sub-second voice turn

True **Voice-to-Voice Latency** is the elapsed time from the **last millisecond of user speech** (`speech_end`) to the **first byte of model audio arriving at the client** (`first_audio_byte`).

<LatencyWaterfall />

| Stage | Typical Duration | What Happens | How to Optimize |
| :--- | :--- | :--- | :--- |
| **1. Network Transport (Client → Backend → Vertex)** | `30–60ms` | 20ms–40ms PCM audio frames traverse WebRTC/WebSocket to the regional endpoint. | Co-locate your Cloud Run / GKE media gateway in `us-central1` alongside the Vertex AI endpoint; use WebRTC (UDP) for the client leg. |
| **2. VAD Silence Duration (`silenceDurationMs`)** | `300–500ms` | The server waits after the user stops speaking to confirm the turn is finished. | Tune `silenceDurationMs` down from `500ms` to `350ms` for snappy transactional bots. |
| **3. Model Time-to-First-Audio-Byte (TTFAB)** | `220–350ms` | Gemini Live processes the active context window and synthesizes the first 24kHz PCM chunk. | Keep active context under 5,000 tokens using [SlidingWindow compression](/gemini_live_pipecat/optimization/#pillar-1-native-sliding-window-compression-the-15-minute-ceiling-breaker) and modular prompt cards. |

:::tip[Separating VAD wait time from model inference time]
When logging latency in production, always record **Total Turn Latency** (`speech_end → first_audio_byte`) alongside **Model Inference Latency** (`vad_end_of_speech → first_audio_byte`). Otherwise, a deliberate `600ms` `silenceDurationMs` setting will look like a model slowdown on your dashboards.
:::

## 2. Reading `usageMetadata` on every turn

At the end of every model turn (alongside `turnComplete`), the server emits a `usageMetadata` payload breaking down exact token consumption by modality:

```python
async for response in session.receive():
    if response.usage_metadata:
        usage = response.usage_metadata
        print(f"Turn total tokens: {usage.total_token_count}")
        print(f"Prompt tokens:     {usage.prompt_token_count}")
        print(f"Response tokens:   {usage.response_token_count}")

        # Inspect modality breakdown (TEXT vs AUDIO vs VIDEO)
        for detail in usage.prompt_tokens_details or []:
            print(f"  Input {detail.modality}: {detail.token_count} tok")
        for detail in usage.response_tokens_details or []:
            print(f"  Output {detail.modality}: {detail.token_count} tok")
```

### What to alert on in production
1. **Monotonically rising `Input AUDIO` tokens per turn**: Indicates that `contextWindowCompression` is missing or `trigger_tokens` is set too high, causing the [Carried Audio Tax](/gemini_live_pipecat/pricing/#2-the-multi-turn-carried-audio-tax-quadratic-growth).
2. **High `Input TEXT` tokens on Turn 1 (>1,500 tokens)**: Indicates an oversized static system prompt or bloated MCP/function tool schemas.

## 3. OpenTelemetry per-turn span instrumentation

Emit one OpenTelemetry child span per conversational turn (`gemini_live.turn`) attached to the parent call trace:

```python
import time
from opentelemetry import trace

tracer = trace.get_tracer("gemini.live.voice")

class TurnTelemetryTracker:
    def __init__(self, session_id: str):
        self.session_id = session_id
        self.turn_index = 0
        self.user_speech_ended_at: float | None = None
        self.first_audio_received: bool = False

    def mark_user_speech_end(self):
        self.user_speech_ended_at = time.monotonic()
        self.first_audio_received = False

    def on_first_model_audio_chunk(self):
        if not self.first_audio_received and self.user_speech_ended_at:
            self.first_audio_received = True
            ttfab_ms = (time.monotonic() - self.user_speech_ended_at) * 1000
            return round(ttfab_ms, 1)
        return None

    def record_turn_metrics(self, usage_metadata, ttfab_ms: float | None):
        self.turn_index += 1
        with tracer.start_as_current_span("gemini_live.turn") as span:
            span.set_attribute("session.id", self.session_id)
            span.set_attribute("turn.index", self.turn_index)
            if ttfab_ms is not None:
                span.set_attribute("turn.ttfab_ms", ttfab_ms)
            if usage_metadata:
                span.set_attribute("turn.prompt_tokens", usage_metadata.prompt_token_count or 0)
                span.set_attribute("turn.response_tokens", usage_metadata.response_token_count or 0)
```
